This is a review request automation app called Candidly that I developed and launched on the Shopify app store - unfortunately, it flopped. 

In hindsight, I should've done more market and competitor research, but in any case, I learned more about programming completing this app
compared to any other tutorial, course, class, or project that I completed.

The main functionality of this app includes:

1) Automated review requests, triggered by cron jobs
2) A complete front end widget for displaying and filtering customer reviews
3) A rewards feature that enables stores to configure rewards that incentivize customers to leave better reviews
4) A custom question feature that enables store owners to configure custom questions on their review forms to gain valulable feedback about purchases
